# Pre-PayKernel Development History

This document records that PayKernel began from an independent source-code snapshot of a personal monorepo (`aashahin/payments-sdk` at commit `f83a311`).

**This is not PayKernel release history.**

- Legacy Git history was **not** imported.
- Legacy npm packages under `@abshahin/*` were **not** migrated, deprecated, or republished.
- PayKernel package versions start a new line under `@paykernel/*`.

For active release notes, see each package’s `CHANGELOG.md` and the Changesets workflow.
