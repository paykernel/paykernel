# Pre-PayKernel Development History

PayKernel began from an independent source-code snapshot of a prior personal payment monorepo (source commit `f83a311`).

**This is not PayKernel release history.**

- Prior Git history was **not** imported.
- Prior personal npm packages were **not** migrated, deprecated, or republished.
- PayKernel package versions start a new line under `@paykernel/*`.

For active release notes, see each package’s `CHANGELOG.md` and the Changesets workflow.
